# 功能范围

系统是「考试 + 问卷 + 题库 + 练习」四块，围绕职业技能等级认定场景。这里记录**做了什么**和**有意不做什么**。

## 已实现

### 考试

- 空白建卷 / 手工加题 / 从题库组卷（选题库 → 按题型配题数与每题分值 → 自动汇总总分）
- 14 种题型：单选、多选、判断、填空、多空填空、评分、NPS、矩阵单选/多选/填空、级联、地址、多行文本等
- 编辑器：大纲树、属性面板、选项编辑、规则（显隐/必填）、拖拽排序、右键菜单、主题、JSON 视图
- 答题：一页一题 / 滚动、答题卡、进度条、字号调节、必填校验、二次确认
- 考试控制：起止时间、限时倒计时、切屏检测、随机题目顺序、闯关模式
- 判分与结果：自动判分、成绩单、排名、逐题解析

### 问卷

- 报名收集、满意度调查、信息登记
- 密码访问、登录后填写、提交后跳转、允许修改答案

### 题库

- 按专业/等级/课程分类，支持按分类分组浏览
- Excel 导入导出（按题型分 sheet）
- 题目增删改查：题干、选项、正确答案、分值、解析、标签
- 组卷按题型随机抽取
- 按用户组（班级）授权，组员自动继承；授权父组覆盖子组

### 练习（学员）

- 整库顺序练习 / 随机抽取（按题型配数量）/ 继续上次练习
- 一页一题或瀑布流、字号调节、进度本地保存
- 错题本（我的笔记）

### 数据与统计

- 答卷电子表格：按题目展开、筛选、排序、编辑、补录、导入导出、回收站
- 逐题统计：选项分布、答题人数；图表支持条形/柱形/扇形切换
- 答卷与统计数据导出 Excel

### 账号与权限

见 `permissions.md`。三角色（管理员/老师/学员），菜单、页面、按钮三级过滤。

### 其它

- 品牌可配置：系统名、简称、Logo、Favicon、版权、备案号
- 亮/暗双主题、整页缩放、手机端底栏与卡片布局
- 考试/问卷批量设置（12+ 项）与批量授权给班级
- 用户组（班级）管理与左树右表用户管理
- 用户注册（手机号 + 姓名 + 密码，待审核）
- 公开查询结果页

## 有意不做

| 模块 | 原因 |
|---|---|
| 模板广场 | 后端创建项目不读模板，模板只在客户端 localStorage 里参与，删了不影响任何流程 |
| 流程编排 | `flow` 模块不在 api 构建里，`/api/workflow/*` 实际 404 |
| 系统管理·职务 | 唯一下游是工作流的按岗位选审批人，权限体系用不到 |
| 系统管理·数据字典 | 只在题目 `dataType=selectDict` 时使用，初始库没有默认字典 |
| 角色权限矩阵编辑页 | 权限体系需要角色数据，但不提供可视化编辑（用 SQL 或接口维护） |
| MCP 智能体接入 | 那是企业版能力，开源的代码库里没有实现 |

> 这些只是**前端不写页面**，后端接口与数据都保留，随时可以加回来。

## 已知缺口

| 项 | 状态 |
|---|---|
| 多库支持（SQLite 等） | 只支持 MySQL 8，没有迁移工具 |
| 整站备份 | 只有脚本（`scripts/deploy/backup.*`），没有产品化按钮 |
| 练习记录 | 答题能存，但 `/api/exercise/list` 的练习历史需要前端补传 `examExerciseType` |
| 学员「我的任务」的答题状态 | 基于本地 localStorage 判断，换设备看不出来（需要后端返回当前用户答卷状态） |
| 标签筛选（题库内） | 后端 `listTag` 硬编码 `question_type=Survey`，题库题型查不到；已移除该控件并留 TODO |
| 白名单 | 后端支持 `whitelistLimit`，前端没做配置入口 |
