# 界面风格

整体是「工程蓝图」风格：等宽字体、直角、白线、网格底、橙色标注。亮色模式是同一套语言换成米白纸面。

## 两套主题

| | 暗色（默认） | 亮色 |
|---|---|---|
| 底色 | `#1e3a5f` | `#f7f5f0`（米白） |
| 网格线 | `rgba(255,255,255,0.05)` | `rgba(30,58,95,0.06)` |
| 主文字 | `#ffffff` | `#1e3a5f` |
| 次要文字 | `#cfe2f6` | `#3f4c5c` |
| 边框 | `rgba(255,255,255,0.38)` | `#b8b1a2` |
| 强调 | `#ff6b35`（工程橙） | `#c2410c`（白底上更深） |
| 主控色 | `#2f6fb5` | `#c2410c` |

对比度按 WCAG 相对亮度公式实算：正文 ≥4.5:1，边框/图形/选中态等非文本 ≥3:1。

切换在顶栏（月亮/太阳），选择存 `localStorage['sk-theme']`。

## 硬性规则

- **圆角 0**：全主题 `borderRadius: 0`，不要出现圆角卡片/按钮
- **不要渐变、不要霓虹阴影**
- **等宽字体**：Cascadia Mono / Consolas，中文回退微软雅黑
- **新增组件不写死颜色**：用 `var(--bp-*)` 变量或 antd token
- **颜色只改一处**：色值只在 `client/src/theme.ts`（antd token）与 `client/src/styles/global.css`（`--bp-*` 两套主题块）里定义，页面 CSS 一律引用变量
- **选中态不得只靠底色**：底色差异单独达不到 3:1，必须叠加 2px 边框 + 字重 + 反色键标等多通道区分（WCAG 1.4.1）

## 工具类

| 类名 | 用途 |
|---|---|
| `.bp-corners` | 容器四角白线装饰 |
| `.bp-card` | 卡片底色 + 描边（替代 inline `rgba(30,58,95,0.55)`） |
| `.bp-dim` | 虚线辅助线 |
| `.bp-tag` | 橙色编号块 |
| `.bp-title` | 等宽标题 |
| `.sk-option` | 答题选项卡片（整行可点，A/B/C 字母标） |
| `.sk-matrix` | 矩阵题表格（窄屏自身横滚） |
| `.sk-mobile-tabbar` | 手机端底部导航 |

## 移动端

- 断点 `767.98px`（与 antd `md` 对齐）
- 桌面侧栏 → 手机底部 TabBar
- 列表在手机上改成卡片（按钮高度 ≥36px）
- 答题页字号可调（0.9×–2.0×），老师年纪大时用得上
- 顶栏有整页缩放（90%–175%）

## 答题页

- 一页一题 / 滚动两种模式
- 选项是整行卡片：左侧字母标；选中态为提亮底色 + 2px 橙边 + 字重 600 + 反色字母标，四个通道同时区分
- 鼠标悬停在已选项上保持选中样式（hover 规则已排除 `.selected`）
- 顶部：进度条、字号 `A- 滑块 A+`、答题卡入口
- 一页一题时「上一题 / 下一题」放在题目正下方（不放屏幕底部）
- 必填未答时点提交 → 不弹确认框，直接提示并跳到那道题
