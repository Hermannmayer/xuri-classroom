# 通用使用指南

面向管理员、老师和学员的通用说明。

## 第一次使用：先看这张地图

<!-- summary: 用 1 分钟认识首页、教学、题库、问卷和系统管理分别在哪里。; category: 快速开始; keywords: 新手,入口,菜单,首页,地图,怎么用 -->

### 常用入口

- 首页：查看待办、近期考试、公告和快捷入口。
- 教学：老师管理试卷、班级和学情；学员会在「我的任务」里看到待完成考试。
- 问卷：创建和查看普通问卷。
- 题库中心：维护题目、从题库组卷、导入导出题目。
- 系统管理：管理员维护用户、权限、公告、系统设置和操作日志。

### 右上角工具栏

- 「缩放」调整界面大小，适合投影或视力不好的老师。
- 月亮/太阳图标切换暗色/亮色模式。
- 问号图标打开帮助中心，可搜索功能说明。
- 头像菜单可进入账号设置或退出登录。

## 登录、账号与界面显示

<!-- summary: 登录失败、修改密码、缩放界面、切换主题时看这里。; category: 账号与界面; keywords: 登录,密码,账号,缩放,暗色,主题,头像,退出 -->

### 登录

- 使用管理员或老师分配的账号登录；忘记密码请联系管理员重置。
- 登录页提示“账号或密码错误”时，先确认大小写和输入法，不要连续多次尝试。

### 界面缩放与主题

- 右上角 90% / 100% / 115% / 130% 可直接切换，设置会跟随账号保存。
- 暗色模式适合夜间使用；切换后刷新页面仍会保留。

## 公告中心：系统通知在哪里看

<!-- summary: 版本更新、考试安排和校内通知都会出现在右上角公告铃铛里。; category: 公告与通知; keywords: 公告,通知,铃铛,未读,更新,版本 -->

### 查看公告

- 点击右上角铃铛打开公告中心，未读数量会显示在图标上。
- 公告可能按全体、老师、学员或班级投放；看不到某条公告时先确认自己的角色和班级。

## 常见问题：图片、手机显示和导出

<!-- summary: 图片太大、手机上错位、导出文档没图时先看这几条。; category: 常见问题; keywords: 图片,太大,错位,手机,导出,Word,没有图片,放大 -->

### 图片显示

- 题干/选项图片在页面上会按卡片宽度缩放；点击图片可看大图。
- 手机上图片会自动换行；如果仍然错位，刷新页面或换最新浏览器。

### 导出文档

- Word 导出会内嵌题干、选项和描述图片；如果原图已被清理，文档里会缺这张图。
- JSON 备份保存图片引用，不保存二进制；跨服务器迁移要同时迁移文件存储。
