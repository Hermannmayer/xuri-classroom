# 管理员使用指南

管理员优先看用户权限和系统设置；老师侧的建卷、题库说明在“老师使用指南”。

## 管理员：用户、角色与权限

<!-- summary: 新建老师/学员、分配角色、控制菜单和操作权限。; category: 管理员指南; permission: system:user:list; keywords: 管理员,用户,角色,权限,老师,学员,账号 -->

### 用户与角色

- 进入「系统管理 → 用户与权限」维护用户、角色和用户组。
- 新增老师/学员时选择对应角色；权限决定能看到哪些菜单和按钮。
- 权限变更后让对方退出重登，确保新权限生效。

## 管理员：系统设置、AI 与导出密码

<!-- summary: 系统名称、AI 模型、导出密码、存储和版本升级都在系统设置里。; category: 管理员指南; permission: system:setting:update; keywords: 系统设置,AI,模型,导出密码,存储,升级,备份,版本 -->

### 系统设置

- 「系统设置」里可改系统名称、登录页、导出密码、AI 服务商和模型。
- AI 模型要在「模型目录 → 能力」里勾选输入类型；需要图片题时勾「图片」。
- 导出密码开启后，题库/答卷/试卷导出都会要求输入密码。

### 升级与备份

- 版本升级请走系统设置里的升级入口，升级前先看版本说明。
- 数据库和附件备份由运维策略负责；普通管理员不要直接改数据库。

## 管理员：公告发布与归档

<!-- summary: 面向全体、老师、学员或班级发通知，并管理已发布公告。; category: 管理员指南; permission: notice:manage:system; keywords: 公告,通知,发布,归档,班级,管理员 -->

### 发布公告

- 进入「系统管理 → 公告管理」新建公告，选择投放范围和有效期。
- 发布后会出现在对应角色的公告中心；过期后不再展示，数据仍保留。
- 删除公告前确认不再需要，删除后师生都看不到。

## 管理员：操作日志与问题排查

<!-- summary: 谁在什么时候改了什么、导出了什么，都可以在操作日志里查。; category: 管理员指南; permission: system:log:list; keywords: 日志,审计,排查,导出,谁改的,管理员 -->

### 查日志

- 进入「系统管理 → 操作日志」，按操作人、动作或时间筛选。
- 导入、导出、权限变更都会留下记录；排查争议时先看日志再改数据。
