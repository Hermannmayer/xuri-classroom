## 2.3.5

### 新功能

- **题库**：题库统计页与列表入口，新增 `repo:report` 权限（学员不可见）。
- **更新**：系统设置可下载更新包并校验 sha256；CI 发版产出 `update.json`。
- **教学**：班级列表与班级试卷改卡片；新增班级详情路由 `/teaching/classes/:classId`。
- **导航**：问卷独立为一级菜单；题库中心合并为一级入口；教学拆成试卷/班级两个子项。
- **答卷**：数据页新增「AI 待复核」筛选，列表标出含 AI 预批改分数的答卷。

### 修复

- **答卷**：批改状态机（白名单交卷洗状态、主观题无 manual 默认、Excel 导入绕过状态机、存量回填迁移）。
- **题库**：收藏一道题库里不存在的题不再 500。
- **数据**：答卷详情抽屉关不掉（关闭时没清 URL 的 `answerId`）；选择题答案显示 optionId 而非选项文本。
- **Schema**：版本探测优先信 `t_schema_version`，纯数据迁移不再被结构探测跳过。
- **安全**：题库统计补 `assertReadableRepo`，防止越权查看未授权题库的统计。

### 性能

- **项目**：待批改答卷数改为一次 group by 聚合，去掉逐项目 count 的 N+1。

### 界面

- 移动端全站适配：首页概览、设置页、班级、答题页、AI 助手、公告中心、编辑器。
- 宽屏：首页去掉 1200px 固定宽度，2K/4K 下图表卡改 3~4 列。
- 默认主题由暗色改为亮色（含 V2.3.5 迁移）。

## 2.3.6

### 新功能

- **AI**：模型目录支持供应商预设、获取模型 ID、设置显示名/上下文窗口/最大输出/输入类型（文本/图片）；已有模型和默认模型会正确回显。
- **答题**：新增「答题后自动下一题」，支持一页一题和瀑布流；练习模式、闯关模式不生效。

### 修复

- **更新**：更新检查状态持久化到 `t_sys_info.setting.updateStatus`，刷新/重启后仍显示上次检查；修复 `setting` 列超长问题。
- **教学**：手机端班级页去掉横向滚动条、压缩空白；任课老师弹窗改卡片列表。
- **系统**：系统首页卡片对比度；用户组/审计/公告/权限页手机布局。
- **公告**：公告分类改两列网格，消除竖排和横向滚动。
- **部署**：修复 web-watch 重建后发布脚本等待前端构建卡住。

## 2.3.7

### 新功能

- **更新**：下载改为后台任务，显示已下载字节、总大小、百分比、速度、当前重试次数；失败自动重试 3 次。
- **更新**：下载记录持久保存，可查看版本/大小/时间，支持单条删除和一键清空；下载完成后自动校验 sha256。
- **更新**：主按钮改为「一键更新」：下载完成后自动安装并重启；Docker、Linux systemd 直装、Windows 便携版三端分别处理 jar 替换和重启。
- **更新**：Windows 生成更新 helper，等待主进程退出后替换 jar 并执行 `start.cmd`；Linux 依赖 systemd `Restart=always`；Docker 使用可写 build 目录和容器重启策略。

### 修复

- **发布**：补回 Windows 发布模板的 UTF-8 BOM，Windows 包不再因编码校验失败。
- **更新**：修复更新检查状态只存内存、刷新/重启后丢失的问题。

### 升级

无数据库结构变更。2.3.7 是首个包含应用内更新器的版本：当前 2.3.5/2.3.6 需要先用发布包或现有脚本升级到 2.3.7 一次，之后才能使用三端一键更新。

## 2.3.8

### 修复

- **更新**：GitHub Release 的 `update.json` 拉取失败或超时时，改为从 Release assets 直接解析 jar 与各端下载 URL，不再误报「Release 缺 update.json」。
- **更新**：新增 `UPDATE_DOWNLOAD_PROXY` 配置，GitHub 资产域不可达时可指定镜像前缀；下载仍优先校验 `update.json` 里的 sha256。

### 升级

无数据库结构变更。2.3.7 可在系统设置中直接检查 2.3.8；如果服务器访问 GitHub `release-assets` 超时，需要配置 `UPDATE_DOWNLOAD_PROXY`（例如可用的 GitHub 资产镜像）或改善服务器网络。

## 2.3.9

### 新功能

- **更新**：默认按 `ghfast.top` → `gh-proxy.com` → `ghproxy.net` → GitHub 直连的顺序下载；连接超时、HTTP 错误、jar 大小或 sha256 不符会自动切换下一条线路。
- **更新**：新增 `UPDATE_DOWNLOAD_MIRRORS`，支持多个逗号分隔的镜像模板和 `{url}`、`{version}`、`{file}` 占位符；设置为 `none` 可强制只走直连。
- **更新**：下载状态显示实际线路，并区分 sha256 校验通过 / Release 未提供 sha256。
- **更新**：自定义更新清单失败时自动回退 GitHub 检查，不再因清单单点故障直接失败。

### 升级

无数据库结构变更。公共镜像属于第三方服务，异常时会自动切换；生产环境可以继续使用默认多镜像，也可以把 `UPDATE_DOWNLOAD_MIRRORS` 换成自己的镜像地址。

> 本次不接入 GitCode 仓库；如需国内自有源，优先使用自建 `update.json` + 对象存储/静态服务器，或把自己的发布镜像配置到 `UPDATE_DOWNLOAD_MIRRORS`。
