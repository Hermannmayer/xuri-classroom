## v2.3.0 (2026-11-17)

> ⚠️ 本版本数据层与运行时变化较大，**升级前请先备份数据库、附件目录与配置**（升级脚本也会自动备份并校验）。详见文末「升级提示」。

### 新功能

- AI 助手改为右下角悬浮对话框，支持多轮对话与动作结果卡；在对话框里直接说「把这个班没批的卷子批了」就能批卷
- AI 能力补全：从题库抽题组卷、试卷质检、题库体检、错题重练、公告草稿、批量批改建议、题干改写
- AI 设置页新增「从服务商获取模型列表」，可直接拉取可选模型；补齐对话与意图识别的职责边界（无关请求回绝、拒绝作弊/泄题、不代替老师下结论）
- 答卷数据页六维筛选（班级 / 交卷时间 / 交卷状态 / 批改状态 / 分数段 / 姓名），选「未交」直接列出未交名单
- 勾选批量导出：Excel 明细、成绩单 PDF、答题卷 PDF、答卷长图、成绩确认单；导出范围可选「当前筛选」或「仅勾选」
- 答题卷 PDF 与学员答题页一致（题干、选项方框、填空/简答原文、签名与上传图片）；长图每人一张，适合微信发送
- 成绩确认单改为整班一张表（每人一行，签名列留空手写），跨班导出自动横向、超页重复表头
- 学情报表支持班级 + 时间段筛选，逐题正确率、选项分布、平均分走势
- 首页按管理员 / 老师 / 学员三种视角展示用户构成、开班中、进行中考试、答卷与批改进度、平均分与及格率、近 14 天趋势
- 题目导入扩到编辑器全部可渲染题型：Excel 13 个 sheet（含下拉/级联/评分/NPS/矩阵/上传），另有「高级配置(JSON)」兜底任意题型
- Excel 内嵌图片按题干所在行归属，试卷导入与题库导入都支持；Word 用【矩阵单选】这类标记题型
- 题库导出补齐 13 个 sheet，导出 → 修改 → 再导入不再丢题（含判断题整类丢失的修复）
- MCP Server：手写 JSON-RPC + 令牌体系 + 写操作幂等，导出范围与网页接口一致
- 导航收敛：班级管理并入「教学」，系统管理收敛为 4 项，公告只读；权限点按功能重新分组

### 导出与数据

- 导出 ZIP 按 `成绩单/`、`答题卷/`、`长图/`、`确认单/` 分子目录；签名与上传图片始终包含，答案解析仍可关闭
- 数据页 / 班级抽屉的批改状态、姓名、分数段、含匿名条件会一并带进 PDF / 长图 / 确认单任务，导出的文件与屏幕上的列表是同一批答卷
- 答卷 PDF 内置中文字体，缺字会明确报错而不是出方块；长图自动控制高度上限（超长卷降 DPI）

### 导入与题库

- 题库 / 试卷导入模板重做：13 个题型 sheet + 使用说明；旧的 5 类模板仍可继续导入
- 导入图片改为「贴在题干所在行」即可，跨行/压行的图片会跳过并提示；`.xls` 需另存为 `.xlsx`
- 题库列表的富题干用消毒后的富文本渲染，带图题干不再露出 HTML 标签

### 工程与部署

- 运行时升级：Java 25 + Spring Boot 4.1 / Spring 7 / Jackson 3 / Jakarta；开启虚拟线程
- 前端升级：React 19 / Ant Design 6 / Vite 8 / react-router 7 / TipTap 3；清掉 antd 6 全部弃用 API
- 新增审计明细（改前/改后、来源、请求 id）、操作日志自动保留清理、通知公告中心、检查更新
- MCP / API 令牌与写操作幂等的数据层；导出审计记录真实格式串

### 修复

- 答题页 React #310 白屏（hook 写在提前返回之后）
- 导出：Excel 流式导出静默空字节、PDF 字形兜底、zip 描述符长度为 0 导致「导出后再导入」失败
- 题库导出 sheet 名随服务端语言变化，英文环境下 `True / False` 被 Excel 改写成 `True - False`，导入时判断题整类丢失
- 首页口径：已批改统计漏掉自动判分、题库计数引用了不存在的软删列、平均分走势出现负刻度
- 登录验证码在无字体环境 500、班级资源操作列换行、问卷属性面板残留考试分组等兼容问题

### 升级提示

本版包含 **V2.2.1 ~ V2.2.6 六个数据库迁移**（答卷批改字段、通知表、审计字段、AI 用量、API 令牌、审计索引），应用启动时自动执行；迁移只增量且幂等，**程序可回滚，数据不会自动回滚**。

升级前请备份：

1. 数据库：`mysqldump --single-transaction --routines --triggers <库名> | gzip > db_$(date +%F).sql.gz`
2. 附件目录：打包 `files/`（签名、上传图片、题目图片）
3. 配置：`application.yml` / `.env`（含 `JWT_SECRET`、数据库密码、导出密码）
4. 校验备份可解压、能 `SHOW TABLES`

三端升级命令与失败回滚见 [升级与迁移](https://hermannmayer.github.io/xuri-classroom/deploy/upgrade)。升级后确认 `/api/system/version` 返回 `2.3.0`，再走一遍登录、答题与导出。
