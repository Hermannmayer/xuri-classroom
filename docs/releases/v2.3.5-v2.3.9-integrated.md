# 2.3.5 — 2.3.9 整合更新日志

覆盖 2.3.5 到 2.3.9 的功能、修复与升级说明，按能力域组织。

## 更新与发布

### 更新检查

- 系统设置可检查 GitHub Release，并显示当前版本、最新版本、更新说明和上次检查时间。
- 更新检查状态持久化到 `t_sys_info.setting.updateStatus`，刷新或重启后不会丢失。
- 支持自建 `update.json` 清单；自定义清单失败时会自动回退 GitHub 检查，不再被单点故障卡死。
- GitHub `update.json` 拉取超时时，从 Release assets 直接解析 jar 和三端下载地址，不再误报“Release 缺 update.json”。

### 下载

- 下载改为后台任务，界面显示已下载字节、总大小、百分比、速度、当前重试次数。
- 下载失败自动重试，默认最多 3 轮；每轮内按线路逐个尝试。
- 下载完成后校验文件大小、jar 文件头和 sha256；任一不符会切换到下一条线路。
- 下载记录持久保存，可查看版本、大小、时间，支持单条删除和一键清空。
- 下载状态显示实际线路，例如 `ghfast.top`；同时区分“sha256 校验通过”和“Release 未提供 sha256”。

### 多源与镜像

- 默认下载顺序：
  1. `ghfast.top`
  2. `gh-proxy.com`
  3. `ghproxy.net`
  4. GitHub 直连
- 连接/读取超时、HTTP 错误、文件大小不符、jar 头不正确、sha256 不符，都会自动尝试下一条线路。
- 新增 `UPDATE_DOWNLOAD_MIRRORS`，支持逗号分隔的多个镜像模板：
  - `{url}`：完整 GitHub 资产 URL
  - `{version}`：版本号
  - `{file}`：文件名
- 设置为 `none` 可强制只走 GitHub 直连；旧配置 `UPDATE_DOWNLOAD_PROXY` 继续兼容。
- 支持自建发布镜像或对象存储，例如：
  ```env
  UPDATE_DOWNLOAD_MIRRORS=https://download.example.com/releases/v{version}/{file}
  ```
- 本次不接入 GitCode 仓库；不依赖其注册、实名或审核流程。需要国内自有源时，使用自建静态源或自有镜像。

### 一键安装

- 主按钮为「一键更新」：下载完成后自动安装并重启。
- Docker：备份并替换可写 build 目录中的 jar，退出后由容器 restart policy 拉起。
- Linux systemd 直装：替换安装目录的 `app.jar`，退出后由 `Restart=always` 拉起。
- Windows 便携版：生成更新 helper，等主进程退出后替换 jar，再执行 `start.cmd`。
- 通过 `UPDATE_APPLY_ENABLED=false` 可关闭应用内安装；没有可写 jar 路径时明确返回不支持，不伪造成功。
- 2.3.7 是首个包含应用内更新器的版本；2.3.5/2.3.6 需要先用发布包或现有脚本升级一次。

### 发布质量

- 修复 Windows 发布模板缺少 UTF-8 BOM 导致 PowerShell 5.1 解析中文失败的问题。
- Release 自动生成 `update.json`、`SHA256SUMS` 和 Windows / Linux / Docker / jar 资产。
- 发布流程支持 Windows、Linux、Docker 三端包和 GHCR 镜像。

## AI 与答题

- AI 模型目录支持供应商预设、获取模型 ID、设置显示名、上下文窗口、最大输出、输入类型（文本/图片）。
- 已有模型和默认模型可以正确回显，切换供应商后模型列表不会丢失。
- 答卷数据页增加「AI 待复核」筛选，列表标出含 AI 预批改分数的答卷。
- 新增「答题后自动下一题」，支持一页一题和瀑布流；练习模式、闯关模式不生效。

## 教学、题库与权限

- 题库增加统计页和列表入口，新增 `repo:report` 权限；学员不可见。
- 班级列表和班级试卷改为卡片式，新增班级详情路由 `/teaching/classes/:classId`。
- 问卷独立为一级菜单；题库中心合并为一级入口；教学拆成试卷、班级两个子项。
- 班级页移动端去掉横向滚动条、压缩空白；任课老师弹窗改为卡片列表。
- 批改状态机修复：白名单交卷洗状态、主观题没有 manual 默认、Excel 导入绕过状态机、存量数据回填。
- 题库统计补 `assertReadableRepo`，防止越权查看未授权题库。
- 收藏一道题库里不存在的题不再返回 500。
- 答卷详情抽屉关不掉、选择题答案显示 optionId 而非选项文本的问题修复。

## 系统、移动端与界面

- 移动端全站适配：首页概览、设置页、班级、答题页、AI 助手、公告中心、编辑器。
- 首页去掉 1200px 固定宽度，2K/4K 下图表卡改为 3~4 列。
- 默认主题由暗色改为亮色，包含 `V2.3.5__default_light_theme.sql` 迁移。
- 系统首页卡片对比度、用户组/审计/公告/权限页手机布局修复。
- 公告分类改为两列网格，消除竖排和横向滚动。
- 修复 web-watch 重建后发布脚本等待前端构建卡住的问题。

## 性能、数据与安全

- 待批改答卷数改为一次 `group by` 聚合，去掉逐项目 count 的 N+1。
- 版本探测优先读取 `t_schema_version`，纯数据迁移不再被结构探测跳过。
- 更新包提供 sha256 校验；多镜像下载也会校验文件大小、jar 头和 sha256。
- 更新检查、下载历史、一键安装均受管理员权限控制。

## 升级与兼容

- 2.3.5 包含主题数据迁移；2.3.6–2.3.9 无数据库结构变更。
- 2.3.5/2.3.6 先升级到 2.3.7 或更高版本，之后可使用应用内一键更新。
- 2.3.7 可升级到 2.3.8；2.3.8 可升级到 2.3.9。
- 默认多镜像开箱即用；网络环境稳定时也可设置 `UPDATE_DOWNLOAD_MIRRORS=none` 只走 GitHub 直连。
- 公共镜像属于第三方服务，可能限流或失效；长期使用建议配置自建 `update.json` 或自有静态源。
