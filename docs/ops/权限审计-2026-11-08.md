# 权限与角色审计（2026-11-08）

> 口径：管理员 = 管理权限全集；学员能力（开始答题/开始练习/错题本/题目只读/学员视角/练习记录）
> 是另一条轴，不随管理员全量注入。老师 = 教学、题库、答卷、班级管理；不含系统管理与学员能力。

## 1. 当前角色矩阵

|---|---|---|---|---|---|
| 超级管理员 | admin | 71 | 否 | 是 | 管理权限全集；学员能力不自动注入 |
| 老师 | teacher | 32 | 否 | 否 | 建/编/发考试与问卷、从题库组卷、题库导入、答卷补录/批改、班级管理；**保留 project:create/update，但无 repo:create/update/delete（不能改题库本身），也不能删考试/删答卷/清空回收站** |

- exercise:list 练习记录/练习页
- portal:student 学员视角
