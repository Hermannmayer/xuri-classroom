# 权限全链路矩阵：用户可见入口 → 后端接口

> **基线**：提交 `ab20296`（2026-11-07，工作区干净）。`PermissionEnum.java` 现有 **60** 个权限点；任务书的 65 是改动前口径——`ab20296` 删掉了 `system:user:updatePosition` 与 4 个 `system:position:*`，并把 `project:publish` 接到了独立端点 `/api/project/status`。
> **方法**：左侧菜单（`BasicLayout.tsx`）→ 路由守卫（`router.tsx` + `RequirePerm` + `can()`）→ 页面内按钮 → 前端 API → 后端 `@PreAuthorize` → `@EnableDataPerm` / 手写过滤。结论一律附 `文件:行号`，查不到写「未找到」。
> **注意**：撰写期间 `client/src/pages/system/Permissions.tsx` 与 `client/src/pages/repo/GrantModal.tsx` 正在改版（工作区未提交，后者在加「批量授权」），这两个文件的行号以 `ab20296` 为准；其余文件与 `ab20296` 一致。
> **图例**：✅ 一致 ｜ ⚠️A 有入口无权限（点了才 403）｜ ⚠️B 有权限无接口 ｜ ⚠️C 权限与数据范围不匹配 ｜ ⚠️D 前后端判定不一致
