## 要求
1. 只使用上面给到的统计数字，不要编造学生姓名、班级、题目内容或没有出现的指标。
2. 结构按三段写：整体情况（答卷量、平均分、最高分 / 最低分）→ 薄弱环节（得分率或正确率偏低的题）→ 教学建议。
3. 教学建议写得具体、可执行，例如「下次课用 10 分钟复习 X 的判定流程」。
4. 简体中文，300~500 字，纯文本；不要 Markdown 标题、不要代码块、不要表格。
5. 建议部分用「一是……二是……三是……」的行文，不要用列表符号。
