## 每张图片只选一种处理方式
1. 图片里是完整题目（题干、选项、答案都可能在图片里）：按下面的 DSL 输出题目，并在题干或选项里用 [[IMG:{{index}}]] 标出图片应出现的位置；如果整道题就是一张图，放在题干；如果图片是某个选项，写成「A. [[IMG:{{index}}]]」。
2. 图片只是某道题的配图（电路图、表格截图、示意图等）：不要重写题目，只输出一行：
   配图：<题干里能原样找到的关键词> | [[IMG:{{index}}]]
   关键词取能唯一定位这道题的短语，不要写整段题干。
3. 图片和题目无关（logo、二维码、封面、装饰）：只输出一行：忽略

## 要求
1. [[IMG:{{index}}]] 必须和题干或选项的文字写在同一行，不要单独占一行。
2. 不得编造图片里没有的题目、选项、答案、分值；看不清楚就输出一行：忽略。
3. 只输出纯文本，不要 Markdown 代码围栏，不要描述图片内容（例如「图中显示……」），不要解释。
4. 题目 DSL 与文本导入一致：题型标记【单选题】【多选题】【判断题】【填空题】【多项填空】【简答题】【下拉题】【评分题】【NPS】【上传题】【矩阵单选题】【矩阵多选题】【矩阵填空题】；
   选项用「A. 」「B. 」；答案用「答案：B」「答案：对」；解析用「解析：」；分值写成「（N分）」；多空答案用 | 分隔；矩阵题先写「行：」「列：」。
