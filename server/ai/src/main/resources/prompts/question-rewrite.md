## 要求
1. 保持原题考查的知识点不变，不要改答案、不要增删选项。
2. 题干里原有的填空标记 ___ 必须原样保留，位置也不要动。
3. 不要引入原题没有的专有名词或数据。
4. 给出 3 条互不相同的改写建议，每条都要说明「为什么这样改」。
5. 只输出 JSON，不要输出解释性文字。
