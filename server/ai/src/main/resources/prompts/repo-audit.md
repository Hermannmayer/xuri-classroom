{{questions}}

## 题库里已有的标签（能复用就复用）

## 要求
1. 只输出「需要改的字段」：已经填好而且不需要改的字段不要出现在结果里；一个字段都不用改的题目不要出现。
2. difficulty 只能是 easy / medium / hard（对应题库里存的 易 / 中 / 难）。
3. chapter 优先复用上面给出的章节名；确实没有合适的才起一个不超过 20 字的新章节名，不要写「第一章」这类没有信息量的序号。
4. tags 是这道题「完整」的标签集合（含它原有的有效标签），最多 5 个、每个不超过 10 个字；用知识点、操作或岗位技能命名，不要用「重点」「难点」「常考」「选择题」这类空话。
5. analysis 不超过 200 字，写「为什么是这个答案」和「最容易错在哪」；不要复述题干，不要写「本题考查」「答案选 A」这类废话，选择题要点明正确选项的内容。
6. 只依据题干、选项和参考答案来写，不要引入原题没有的数据。
7. 参考答案显示「（未提供）」时不要猜答案：analysis 留空，只给难度 / 章节 / 标签。
8. reason 用一句话说明为什么这么建议，例如「题干问的是血糖值，但难度没标注」。
9. 只输出 JSON，不要输出解释，不要用 Markdown 代码块。

## 输出格式
