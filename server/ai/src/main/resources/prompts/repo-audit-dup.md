## 判定口径
1. 「重复」指的是同一道题：考查同一个知识点，题干只换了数字、措辞或选项顺序，或者两道题互为改写。
2. 同一个考点下的「不同」题目不算重复（例如「静脉输液的目的」和「静脉输液的注意事项」不是重复）。
3. similarity 是 0~1 的语义相似度：0.9 以上基本是同一道题；0.7~0.9 需要人工确认；0.7 以下不算重复。
4. suggestion 只能取 merge（可以直接合并、保留一道）或 review（必须人工确认）。
5. 明显不重复的组不要出现在输出里；判断为重复或需要人工确认的组必须给出。
6. ids 只能写输入里给出的 id，不要新增、不要改写；不要输出 titles 字段。
7. reason 用一句中文说清判断依据（考点是否相同、题干差在哪），不要复述整段题干。
8. 只输出 JSON，不要输出解释，不要用 Markdown 代码块。

## 输出格式
{"duplicates":[{"ids":["题1","题2"],"similarity":0.95,"reason":"……","suggestion":"merge"}]}
